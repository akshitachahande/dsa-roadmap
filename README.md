# Data Structures & Algorithms

This repository contains the DSA problems I'm solving while working through **Data Structures & Algorithms**.

I'm organising everything topic-wise and using this repository to practise consistently, understand common problem-solving patterns, and keep track of what I've covered.

The goal isn't just to collect solutions. I want to understand **why a solution works, how to arrive at it, and how to recognise similar problems in the future**.

## How I'm approaching DSA

For most problems, I try to go through the following process:

```text
Understand the problem
        ↓
Think of a straightforward solution
        ↓
Look for a better approach
        ↓
Identify the pattern
        ↓
Implement
        ↓
Analyse time & space complexity
        ↓
Test edge cases
```

I'm also trying to focus on recognising **patterns and techniques**, rather than memorising individual solutions.
